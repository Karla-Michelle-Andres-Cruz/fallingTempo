
# Descripcion

En el aprendizaje musical, la constancia y el control del tiempo de práctica son factores fundamentales para lograr un progreso significativo. Sin embargo, muchos estudiantes y músicos no cuentan con una herramienta que les permita registrar, analizar y dar seguimiento a sus sesiones de práctica de manera organizada.

Por esta razón se desarrolla **Falling Tempo**, una aplicación móvil diseñada para ayudar a músicos a registrar sus sesiones de práctica, medir su rendimiento y visualizar su progreso a lo largo del tiempo, brindando una alternativa accesible, funcional y enfocada en las necesidades reales del usuario.

El sistema permitirá almacenar información relacionada con las prácticas musicales, canciones, instrumentos y progreso del usuario mediante una base de datos estructurada y normalizada.

El proyecto **Falling Tempo** tiene como propósito desarrollar una aplicación móvil multiplataforma que permita a los músicos registrar, administrar y analizar sus sesiones de práctica musical de manera organizada y accesible.

La aplicación busca facilitar el seguimiento del tiempo de práctica, el tempo (BPM), el nivel de dificultad, las canciones practicadas y los instrumentos utilizados, permitiendo al usuario visualizar su progreso y rendimiento a lo largo del tiempo.
